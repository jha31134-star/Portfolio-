SmartFrame Hospital: live demo

A hospital management system that stores patients as frames (a knowledge representation technique from AI). Every patient frame inherits default slots from a PATIENT frame, which inherits from PERSON, and a small symptom knowledge base suggests the right department. This is a browser version of my Python and Tkinter desktop app, so you can try it right here.

Demo data is fictional and stays in your browser only. Nothing is sent to a server.

Try symptoms such as headache, dizziness or vomiting, diarrhea. Leave optional fields empty to see the frame defaults. Saving an existing Patient ID replaces that record.
